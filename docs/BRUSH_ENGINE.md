# 画笔与橡皮引擎参考

## 方案选择

本项目需要保留区域裁剪、SVG 导出和离线运行，因此本轮不替换整个画布架构：

| 方案 | 能力与取舍 | 本轮结论 |
| --- | --- | --- |
| [perfect-freehand](https://github.com/steveruizok/perfect-freehand) | MIT；独立的自由手绘轮廓算法，支持真实压力、模拟压力、平滑，可输出 SVG | 接入 npm 固定版本 **1.2.3**，用于轮廓和稳定中心线 |
| [Fabric.js](https://github.com/fabricjs/fabric.js) | MIT；Canvas 对象、画笔和变换等完整能力，也有 SVG 导出 | 能力较广，但需要改造当前 SVG 编辑及区域模型，本轮不接入 |

调用上游公开的 `getStroke` / `getStrokePoints`，没有直接复制 GitHub 项目源码。原始 MIT 许可见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)，构建会将声明带入 `dist/`。

## 预设与行为

| ID | 名称 | 实现 | 默认大小 / 透明度或强度 |
| --- | --- | --- | --- |
| `round` | 圆头笔 | 恒定宽度的平滑填充轮廓 | 4 px / 100% |
| `ink` | 压感墨笔 | 轮廓宽度随压力变化，可关闭压感 | 14 px / 100% |
| `pencil` | 纹理铅笔 | 压感轮廓 + 固定种子的 SVG 颗粒滤镜 | 8 px / 80% |
| `marker` | 荧光笔 | 固定方向的扁矩形笔头连续扫过，整体半透明 | 28 px / 35% |
| `hard` | 硬边橡皮 | 圆形轮廓写入区域擦除遮罩 | 24 px / 100% |
| `soft` | 柔边橡皮 | 圆形轮廓先高斯羽化，再写入擦除遮罩 | 48 px / 100% |
| `block` | 方形橡皮 | 方形笔头连续扫过，形成无间隙擦除形状 | 32 px / 100% |

每种预设独立记住当前大小、透明度/擦除强度、平滑度和压感开关。它们是页面内工具设置，不是跨刷新保存的用户配置；已绘笔画的参数始终随文档保存。本地作品另存当前画笔颜色，并由自绘色轮调整，见[绘画库参考](DRAWING_LIBRARY.md)。

- 画笔大小：1–100 px；橡皮大小：1–160 px，**不再自动乘二**。
- 工具设置中的透明度/强度：5–100%；模型允许 0–1。
- 平滑度：0–100%，影响边缘平滑和中心线稳定程度，不是延迟采样数量。
- 压感只作用于墨笔和铅笔；圆头笔、荧光笔和橡皮保持预设宽度。
- 圆形/矩形光标表示标称笔头大小；柔边外圈约为额外三倍高斯标准差，仅提示羽化影响范围，最终仍按框裁剪。
- 形态预览为缩小展示，并不代表实际画布尺寸。

## 采样与压力

每个采样点保留 `x`、`y`，笔设备额外保存 `pressure ∈ [0,1]`。

`pressureMode` 的含义：

- `constant`：恒定宽度，忽略压力变化。
- `stylus`：仅 `pointerType === "pen"` 且启用压感时使用真实 `PointerEvent.pressure`。
- `simulated`：鼠标/触控启用压感时，交给 perfect-freehand 按采样间距估计粗细；这不是硬件压力，也不是物理速度测量。

合并指针事件可用时读取 `getCoalescedEvents()`；不可用时退回普通事件。相同位置但压力变化的采样仍会保留。抬笔事件常把压力归零，因此最终位置复用最后有效压力，避免尾段突然塌缩。

参数在起笔时冻结；中途修改设置会取消草稿，不会让同一笔画前后使用不同的预设。

## SVG 渲染

- 笔画主要输出封闭的填充 `path`，不需要 Canvas 截图或远程纹理。
- 矩形笔头以相邻两个笔头角点的凸包连续扫过，避免快画/斜线产生盖章间隙。
- 一个笔画使用一个透明度，即使荧光笔在同一笔画中折返，也不因分段重叠重复加深；分次绘画则会正常叠加。
- 铅笔使用固定 `feTurbulence` 种子，编辑与导出复用同一纹理；不同浏览器的滤镜和抗锯齿细节仍可能有微小差异。
- 柔边橡皮使用高斯滤镜，滤镜范围限制在区域局部边界内。
- 每条擦除只遮罩本框之前的墨迹，后续笔画不受影响。低强度多次擦除会累积减淡，同一笔画内部不按采样次数重复擦除。
- 擦除、纹理、粗笔刷和羽化都在区域的最终 `clipPath` 内，不能污染其他区域或背景。

HTML/SVG 导出只保留已生成的矢量和滤镜，**不加载 perfect-freehand、CDN 或额外纹理资源**。

## 项目数据版本

本轮 JSON 导出升级为 `version: 2`：笔画可增加 `brush`、`opacity`、`smoothing`、`pressureMode`，采样点可增加 `pressure`。

旧笔画缺少 `brush` 时，仍走原先的圆头描边路径；缺失透明度按 1 处理。因此在模型/渲染层可以混合处理旧笔画和新笔画，但**尚未提供 JSON 导入入口**，也不能据此推断已有文件可直接导入。

完整模型见[架构参考](ARCHITECTURE.md)。本地绘画库已经按预设与 `kind` 匹配、压力、透明度、平滑度等范围进行校验；未来文件导入应复用校验并补齐版本迁移。

## 本轮未覆盖

- 不模拟颜料扩散、湿边、油画堆积、真实纸张或画布材料。
- 不支持 Photoshop `.abr` 等外部笔刷包，也不从其他应用提取素材。
- 未实现倾斜/方位角、喷枪、逐笔对象橡皮、硬件橡皮尾端或侧键切换。
- 大量长笔画与滤镜仍受当前整文档重渲染、快照和遮罩嵌套的性能限制。
- 压感事件有浏览器自动化覆盖，但真实数位板、手写笔和触控设备仍需人工实测。

若后续需要专业水彩/油画，应另行评估 Canvas/WebGL 的混合渲染、区域隔离以及 SVG 导出时的栅格化策略，而不是把普通矢量预设包装成物理画笔引擎。
