# 绘画库、保存与本地数据

## 使用流程

1. 打开首页 `#/`，点击「新建绘画」，输入名称。创建成功后立即写入一份空白作品并进入工作台。
2. 使用区域、画笔、橡皮和自定义色轮编辑；顶部名称输入可重命名作品。
3. 点击顶部「保存」或 `Ctrl/Cmd+S`。只有事务完成才显示“已保存到此浏览器”。
4. 返回首页，作品按最近保存时间排列，可通过缩略图打开继续编辑。搜索按名称过滤；删除需确认，且不能撤销。

工作台地址为 `#/drawing/<id>`，刷新可恢复该作品上次保存的版本。不存在或已删除的 ID 会提示并返回首页，不会创建同名空作品代替。

## 保存哪些内容

- 作品 ID、名称、创建时间、最后保存时间及版本号。
- 画布尺寸、区域 ID、名称、位置、大小、层级和绑定数据。
- 每个区域内的所有画笔与橡皮记录、预设参数、局部坐标和压力。
- 当前画笔颜色。
- 一张从已提交 SVG 生成的 PNG 缩略图，不包含编辑边框、标签或光标。

不保存未完成的拖动/笔画、当前选择、撤销历史、侧栏状态及其他笔刷面板配置。重新打开时历史清空，避免撤销到另一份作品；笔画自带的大小/透明度/平滑度不会丢失。

生成缩略图失败时仍可保存完整绘画，只是首页显示空白预览。保存与导出不同：保存让当前浏览器继续编辑；HTML/SVG/JSON 导出用于下载和备份，当前尚无 JSON 文件导入入口。

## 存储实现

原生 IndexedDB，无额外运行时库，也不需要后端服务：

- 数据库：`web-drawing-projects`
- 数据库版本：`1`
- 对象仓库：`drawings`
- 主键：`id`

作品记录外层与矢量文档分开版本化：

```ts
type SavedDrawing = {
  schema: 1;
  id: string;
  title: string;
  createdAt: number;
  updatedAt: number;
  revision: number;
  document: DrawingDocument; // 当前 version: 2
  color: string;            // 归一化 #rrggbb
  thumbnail: string | null; // PNG data URL
};
```

完整矢量结构见[架构文档](ARCHITECTURE.md)。数据读取和保存前都会检查版本、ID、重复区域、几何、颜色、预设、压力和绑定参数；当前安全上限为每份 256 个区域、20,000 条记录、500,000 个采样点。超出限制不会覆盖旧数据，应先导出备份再整理作品。

缩略图只接受 PNG data URL，名称通过文本节点展示。保存数据不包含可执行脚本，绑定仍只保存声明，不执行业务动作。

## 一次保存的边界

保存前提交正在输入的区域属性，取消尚未完成的操作，取得模型快照并生成缩略图。异步写入中仍允许编辑：若后来继续画，保存完成后这些新修改仍显示未保存，不会被旧快照反向覆盖。

记录读取、版本检查和写入在同一个 read-write 事务内。只有传入的 `revision` 与当前记录一致时才更新；创建传入 `0`，每次更新递增。

因此：

- 两个页面同时编辑，旧页面不能覆盖新页面已保存的版本。
- 在另一个页面已删除的作品，不会被旧页面的保存意外复活。
- 保存失败、数据校验失败或冲突时，原先保存版本保持不变。

冲突提示后应先导出当前编辑内容，再重新打开较新版本进行整理。当前没有自动合并或云同步。

## 未保存与离开

顶部状态比较作品名称、当前颜色、已提交区域和待提交属性输入；恢复到保存基线（例如撤销最后一次改动）后会重新显示已保存。

- 应用内离开：可选「保存并离开」「不保存并离开」「取消」。保存失败会留在工作台。
- 刷新/关闭：使用浏览器的 `beforeunload` 提醒。提醒文字由浏览器控制，部分移动浏览器或系统强制终止页面时无法保证提示。
- 丢弃修改只回到上次保存状态，不删除作品。
- 新建作品已保存空白记录；若未保存绘画就放弃，首页仍保留这份空白作品。

**当前没有自动保存或崩溃恢复。** 对话框提醒不能代替定期保存。

## 存储失败和损坏

- 不支持/禁止 IndexedDB：显示读取或新建失败，不假装保存成功。
- 空间不足、权限受限、事务中断：保留当前内存绘画和未保存状态，提示先导出备份。
- 损坏/未知版本：不渲染、不覆盖；首页显示有多少份记录无法读取，其余有效作品仍可使用。修复或迁移暂需开发工具处理。
- 删除只有当前记录，不会清空整个数据库。

## 本地数据边界

作品仅属于**当前浏览器配置和当前源**（协议、域名、端口）：

- `localhost:3000` 与 `localhost:3001` 是不同的绘画库。
- 更换设备、浏览器或用户配置不会带走作品。
- 无痕模式结束、清除网站数据、浏览器自动回收空间可能删除作品。
- 不提供账号、服务器备份、云同步或永久保存保证。

建议定期导出项目 JSON 留存数据，并导出 HTML/SVG 保存可直接查看的成品。不要直接修改数据库或删除站点数据，除非已确认完成备份。

## 色轮与移动

- 颜色使用自绘 Canvas 色相环与饱和度/明度面板，不使用系统默认颜色选择器。
- 三个带标签的滑块、HEX 输入和常用色按钮提供完整键盘入口；HSV 与 HEX 转换逻辑独立可测试。
- 区域移动仅改变 `rect.x/y`；局部笔画、擦除记录和绑定不变。范围限制在画布内，拖动松开后只提交一条历史记录。
- 宽高调整仅修改 `rect.width/height`，固定左上角，不缩放笔画。缩小保留所有隐藏记录，保存时不会裁掉原始采样；刷新后重新扩大仍能显示。数据结构保持文档版本 2，不需要迁移旧作品。
- 重叠位置优先拖动最上层框；被覆盖的下层框可先从列表选择，再用坐标或方向键移动。
