# 操作参考

## 1. 首页、新建与继续编辑

首页是本地绘画库，可看到作品名称、缩略图、区域数量及最近保存时间。

- 点击「新建绘画」输入名称，创建成功后进入空白工作台；不填名称时使用“未命名绘画”。
- 点击作品卡片继续编辑；名称搜索可过滤列表。
- 删除需确认，会删除该份本地作品且不能撤销，不影响其他作品。
- 工作台左上角的首页按钮返回绘画库；有未保存修改时会提供保存、放弃或取消选项。

## 2. 创建区域

初始画布为空，底面背景锁定，不能直接绘画。

- 点击「框选」或按 `R`，支持从任意方向拖出矩形。
- 松开后新区域置顶、选中，并切换到画笔。
- 单击、零宽高或小于 12 × 12 px 的拖动不创建区域；越出画布时按边界收束。
- 侧栏的「精确创建区域」可输入 X、Y、宽度和高度。原点为左上角，单位为 SVG 逻辑像素。

区域可以移动，但目前不能缩放或修改宽高。

## 3. 选择、移动与绘画

左侧列表**上层在前**，点击一行会选中对应区域并切换到画笔。

「选择」工具（`V`）：

- 点击/拖动时命中最上层的框，包括该框中没有笔画的透明部分。
- 按住拖动可移动整层，框内笔画、橡皮和绑定一起跟随，层级不变。
- 区域不能移出画布；一次拖动只生成一个撤销步骤。
- 选中框后，方向键微调 1 px，`Shift + 方向键` 移动 10 px；也可在属性面板修改区域 X/Y。
- 要移动被覆盖的下层框，可从列表选择，再按 `V` 用方向键调整，或直接输入坐标；鼠标重叠命中仍优先上层。
- 点击框外取消选择，`P` 返回画笔。

绘画只认**当前选中框**，不会自动切换目标：

- 必须在框内起笔；从框外按下再拖入不会产生笔画。
- 起笔后可以出框再回来，越界轨迹及整支笔刷外形都会裁剪。
- 下层框的内容仍按真实层级显示，可能被上层笔画遮挡；选中框线不表示内容已置顶。
- Esc、切换工具、指针取消或窗口失焦会取消未完成的框选、移动或笔画。

## 4. 画笔、橡皮与色轮

四种画笔：圆头笔、压感墨笔、纹理铅笔、荧光笔。三种橡皮：硬边、柔边、方形。

- 画笔大小 1–100 px，橡皮 1–160 px，不再按画笔大小乘二。
- 每种预设单独记住页面内的大小、透明度/强度、平滑度、压感开关。
- 墨笔和铅笔可使用笔设备真实压力；鼠标/触控按采样间距模拟粗细，也可关闭压感。
- 平滑度影响轨迹稳定，不是硬度。缩小的形态预览不等于实际尺寸，光标表示标称笔头大小。
- 荧光笔在同一笔中折返不重复加深，分次起笔则叠色。
- 橡皮只擦除当前框之前的墨迹，不影响其他框或之后补画的笔画。
- 擦除是透明而不是涂白，可显露下层；低强度可分次擦淡，柔边外圈表示近似羽化范围，仍受框裁剪。

画笔模式点击圆形颜色按钮打开自定义色轮：

1. 外环拖动选择色相。
2. 内面板横向调饱和度，纵向调明度。
3. 也可使用三个滑块、HEX 输入或常用色；全部可用键盘操作。
4. HEX 接受 3 位或 6 位格式，非法输入会提示，不改变有效颜色；“完成”或关闭对话框保留当前颜色。

颜色修改只影响后续笔画，不回溯修改旧笔画。保存作品会保留当前颜色；其他工具面板配置不跨刷新保存。更多限制见[画笔引擎参考](BRUSH_ENGINE.md)。

## 5. 区域管理与撤销

- 区域名在离开输入框时提交；空名称恢复原值。
- 上移/下移一层只修改叠放顺序，不改变 ID、位置、局部笔画或绑定。
- 删除区域连同其笔画和绑定一起删除，可以撤销；这与首页不可撤销的作品删除不同。
- 创建、移动、画笔、擦除、改名、层级和删除都支持撤销/重做，最多保留 80 个快照。
- 撤销后进行新编辑会清除旧重做分支；重新打开作品会清空历史。
- 文本/数值输入时不抢占删除、工具字母和文本撤销快捷键；保存快捷键始终用于作品保存，并先提交当前区域属性。

## 6. 保存与备份

顶部作品名称可直接编辑；「保存」或 `Ctrl/Cmd+S` 保存完整绘画到当前浏览器。事务完成后显示“已保存到此浏览器”，修改后显示未保存。

**这不是自动保存或云同步。** 刷新只恢复上次保存版本；清除网站数据、切换浏览器/端口或无痕窗口结束都可能使作品不可用。

保存失败时不要直接关闭，先通过顶部「导出」备份。多页面冲突会阻止旧页面覆盖新版本，详见[绘画库与本地数据](DRAWING_LIBRARY.md)。

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| HTML | SVG、样式、项目 JSON 和区域激活事件桥接 | 独立离线展示与集成 |
| SVG | 图层、裁剪、纹理、笔画及擦除 | 矢量成品 |
| JSON | 文档版本 2、区域、笔刷参数、压力和绑定 | 数据备份与外部处理 |

导出仅含已完成内容，没有编辑边框、标签、大小光标或临时预览。边框是编辑边界，不是成品装饰线。

本地绘画库可以重新打开保存记录，但当前**没有 JSON 文件导入入口**。JSON 下载并不意味着已支持把文件重新导回；HTML 可独立查看成品。

## 7. 常见问题

**为什么画不出来？** 确认已选框、使用画笔且起笔在框内；下层框也可能被上层遮挡。

**返回首页后发现是一张空白作品？** 新建时会保存空白记录，后续绘画仍需点击保存；放弃修改会回到上次保存版本。

**为什么换端口看不到作品？** 本地数据按协议、域名、端口隔离，并不是文件丢失或已同步到其他地址。

**可以绑定按钮或链接吗？** 目前仍只保留区域 ID、绑定字段和导出事件接口，没有业务配置面板，参考[绑定接口](REGION_BINDINGS.md)。

**小屏如何准确操作？** 展开侧栏用坐标表单创建或移动。工作区缩放和平移仍在 [ROADMAP](../ROADMAP.md) 中。
