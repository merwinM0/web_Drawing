# 操作参考

## 1. 创建区域

初始画布为空，底面背景锁定，不能直接绘画。

- 点击「框选」或按 `R`，在画布上拖动。支持从任意方向拖出矩形。
- 松开后新区域自动置顶、选中，并切换到画笔。
- 单击、零宽高或小于 12 × 12 px 的拖动不会创建区域。
- 越出画布的框选会按画布边界收束。
- 也可以展开侧边栏的「精确创建区域」，输入 X、Y、宽度、高度后创建。坐标原点是画布左上角，单位为 SVG 逻辑像素。

区域创建后目前不能移动或调整尺寸。需要其他尺寸时可重新创建；未来能力见 [ROADMAP](../ROADMAP.md)。

## 2. 选择与绘画

左侧列表**上层在前**，点击某一行会选中该区域并切换到画笔。

「选择」工具（`V`）用于在画布上选框：

- 重叠位置选中最上层的框，包括框内没有笔画的透明位置。
- 点击框外空白取消选择。
- 选择后仍处于选择工具，按 `P` 或点击画笔开始绘画。
- 要选中被覆盖的下层框，请使用左侧列表。

绘画只认**当前选中区域**，不会根据鼠标经过的位置自动切换框：

- 必须从当前框内起笔；从框外按下再拖入不会产生笔画。
- 起笔后可以拖出框，越界部分会被裁剪；回到框内可以继续同一条轨迹。
- 整条笔刷，包括边缘粗细，都不能显示到框外。
- 下层框即使被选中，其内容也仍按实际层级显示，可能被上层笔画覆盖。选中框线只是编辑提示，不代表内容已经置顶。

## 3. 橡皮、重叠与层级

- `E` 切换橡皮，作用范围仍是当前框。
- 橡皮擦除该框中先前的笔画；其他框不受影响，之后补画的笔画不会被旧橡皮继续擦掉。
- 擦除得到透明区域，而非白色涂层，因此会透出下层内容。
- 橡皮直径为当前粗细的两倍，最小 10 px。
- 「上移一层」「下移一层」只改变叠放顺序，不改变区域 ID、位置、笔画或未来绑定。
- 当前层级是平面的前后叠放，不是父子区域或嵌套分组。

## 4. 管理与撤销

- 在区域设置中修改名称，离开输入框时提交；空名称会恢复原值。
- 删除区域会同时删除其笔画和绑定数据；可以撤销。
- 创建、绘画、擦除、改名、重排、删除都支持撤销/重做，最多保留 80 个快照。
- 切换工具、按 `Esc`、指针取消或窗口失焦会丢弃尚未完成的框选/笔画。
- 撤销后进行新的编辑，会清除旧的重做分支。
- 文本或数值输入时，编辑器不会抢占删除、工具字母键和文本撤销快捷键。

## 5. 导出与保存

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| HTML | 区域 SVG、样式、项目 JSON、区域激活事件桥接 | 独立离线展示与后续功能集成 |
| SVG | 图层顺序、区域裁剪、笔画和橡皮遮罩 | 矢量图展示与继续加工 |
| JSON | 版本、画布尺寸、区域 ID/名称/边界/笔画/绑定 | 项目数据留存及外部处理 |

导出只包含已完成操作，不包含临时笔画、选中边框、区域标签、工具栏或侧边栏。边框仅是裁剪/命中边界；如需要可见装饰线，请在框内自行绘画。

**当前没有自动保存，也没有项目导入入口。** JSON 目前是数据导出，不承诺能直接在编辑器中重新打开。刷新前应导出，导出 HTML 可离线查看最终视觉。

## 6. 常见疑问

**为什么在某处画不出来？** 先确认已选区域、已切到画笔、起笔在框内。若选中下层框，其笔画也可能被上层内容挡住。

**能否把一个框做成按钮或链接？** 当前只保留区域身份、绑定字段和导出激活事件，不提供业务配置面板，也不会自动跳转或提交表单。参考[区域绑定接口](REGION_BINDINGS.md)。

**小屏如何创建准确的框？** 展开左侧面板使用坐标表单；画布当前整体缩放显示，工作区缩放和平移尚未实现。
