# 架构与数据模型

## 模块边界

| 文件 | 职责 |
| --- | --- |
| `src/app.ts` | 当前工具、临时指针草稿、Pointer Capture、键盘和界面协调 |
| `src/document.ts` | 区域/笔画类型、命中、历史快照和文档修改入口 |
| `src/geometry.ts` | 画布常量、框选归一化、合法尺寸、命中、局部坐标及路径数据 |
| `src/render.ts` | 共用 SVG 内容渲染、区域裁剪、按时间擦除和编辑辅助框 |
| `src/brushes.ts` | 预设、参数/压力校验及 perfect-freehand 适配，矩形笔头扫掠 |
| `src/brush-render.ts` | 笔画轮廓、颗粒纹理、柔边滤镜和旧笔画兼容渲染 |
| `src/brush-panel.ts` | 各预设独立设置、笔触形态预览和标称大小光标 |
| `src/xml.ts` | SVG 文本及属性转义 |
| `src/export.ts` | 项目序列化、离线 HTML 和下载；不读取编辑器 DOM 作为成品 |
| `src/sidebar.ts` | 图层列表、名称/层级/删除操作、精确创建表单及焦点维护 |
| `src/dom.ts` | 带缺失检查的 DOM 查询 |
| `server.ts` | 仅用于开发的 Bun HTML 入口 |

无前端框架。生产依赖 perfect-freehand 在构建时打包进编辑器，不使用 CDN；导出的成品仅含矢量结果和滤镜，不需要该库。开发依赖用于类型检查与浏览器测试。选型和许可见[画笔引擎参考](BRUSH_ENGINE.md)。

## 数据结构

```ts
type DrawingDocument = {
  version: 2;
  width: 1200;
  height: 760;
  regions: Region[]; // 从底到顶
};

type Region = {
  id: string;       // 创建时生成 UUID，生命周期内稳定
  name: string;     // 展示名称，不是业务键
  rect: { x: number; y: number; width: number; height: number };
  marks: Mark[];    // 按产生时间排列，仅属于此框
  binding: RegionBinding | null;
};

type Mark = {
  kind: "pen" | "eraser";
  points: { x: number; y: number; pressure?: number }[]; // 框内局部坐标，压力为 0–1
  width: number;
  color: string; // 橡皮渲染时不使用此颜色
  brush?: "round" | "ink" | "pencil" | "marker" | "hard" | "soft" | "block";
  opacity?: number; // 0–1，橡皮中表示擦除强度
  smoothing?: number; // 0–1
  pressureMode?: "constant" | "simulated" | "stylus";
};
```

完整绑定类型见[区域绑定接口](REGION_BINDINGS.md)。本轮导出升级为版本 2；旧模型笔画不含 `brush` 时仍按版本 1 的原始圆头路径渲染，透明度缺失按 1 处理。当前仍没有项目导入入口。

编辑器另有 `selectedRegionId`，与区域一起进入历史快照；当前工具设置和草稿不单独导出，但每次起笔时复制的预设、颜色、大小等参数会随笔画导出。没有“背景笔画数组”或“按钮组件数组”，所有可编辑笔画统一归属于区域。

`EditorStore` 是文档修改入口。界面不应绕过其方法直接修改 `state`，否则不会生成撤销记录。

## 交互状态

- `region`：拖动创建新框，成功后进入 `pen`。
- `select`：按矩形边界从顶向底命中区域，不添加历史记录。
- `pen` / `eraser`：只允许从选中框内部起笔，按下时固定目标 ID、笔刷参数和区域边界。
- 草稿在 `pointerup` 时才提交；取消、工具切换、撤销和失焦均不提交草稿。
- Pointer Capture 允许拖出画布后仍收到抬起/取消事件；单次只接受一个主指针。
- 指针移动使用 `requestAnimationFrame` 合并渲染，不为每个采样点生成历史步骤。
- 支持合并指针采样；墨笔/铅笔可读取真实笔压力或模拟鼠标粗细，抬笔零压力使用最后有效压力。
- 每种画笔和橡皮预设独立记住设置；参数在起笔时复制到笔画，修改工具参数不改写既有笔画。

## 坐标与裁剪

1. 使用 SVG `getScreenCTM().inverse()` 把浏览器指针位置转换为画布坐标，避免 CSS 缩放造成错位。
2. 框选起终点限制在画布内，矩形反向拖动后归一化。最小尺寸为 12 × 12。
3. 笔画采样减去区域左上角，保存局部坐标。允许中途采样落在区域外，不把每个点强行推到框边缘。
4. 每个区域使用 `transform="translate(x y)"` 和独立 `clipPath`，对**完整笔刷外形**进行裁剪。
5. 编辑辅助框单独渲染，不参与成品导出。

保留越界采样能避免鼠标绕出框时沿边界出现伪笔画；裁剪只决定可见部分，不改变原始轨迹。

## 图层与命中

`regions` 数组是唯一层级来源：前面的在下，后面的在上。界面列表反序展示，命中从末尾开始查找，导出按数组顺序生成同级 SVG 分组。

每个导出区域有覆盖整个矩形的透明命中面。即使顶层框某处没有墨迹，该处也由顶层框接收激活事件，避免业务命中规则依赖手绘笔画形状。

当前只有平面叠放，没有父子关系。选中区域不会自动置顶。

## 橡皮语义

按时间扫描一个框的 `marks`：

- 画笔轮廓追加到已有墨迹之后；荧光笔整条形状仅应用一次透明度。
- 橡皮将硬边轮廓、柔边滤镜或方形扫掠写入白底黑形状的 luminance mask，并仅包裹此前墨迹。强度由形状透明度控制，多次擦除逐步减淡。
- 后续画笔在该遮罩分组之后追加。

因此橡皮透明擦除先前内容，不遮住后画笔画，也不擦除相邻或下层框。每个区域的裁剪和遮罩 ID 都由稳定区域 ID 区分。

代价是长时间编辑可能产生较深的 SVG 遮罩嵌套；缓存、简化和大文档优化列入 [ROADMAP](../ROADMAP.md)。

## 历史

每次有效编辑生成独立 `structuredClone` 快照，最多 80 个（包含当前状态）。撤销/重做恢复区域内容、排序和选择；名称未变化、无效边界或无法继续移动层级时不产生新记录。撤销后新编辑截断重做分支。

快照模型便于验证正确性，但不适合无限量笔画；未来可迁移为命令或增量历史。

## 导出和安全

- 编辑与导出共用 `renderRegions`，避免视觉语义分叉。
- 导出从已提交模型重建 SVG，不克隆含临时 UI 的画布。
- 区域名称和绑定属性进行 XML 转义；HTML 内嵌 JSON 额外转义 `<`、`>`、`&`，避免关闭脚本标签。
- HTML 运行时只派发区域激活事件，不执行 `action` 字符串、不运行用户代码、不打开 URL。
- 当前没有 JSON 导入接口；添加导入前必须实现结构、数量、颜色、坐标、ID 和版本校验。

## 界面设计约束

沿用项目已有的浅色 SVG 工作台、左侧图层和紫色工具选中态，不引入外部视觉模板。主任务是“创建区域 → 选择笔触 → 区域内绘画”，不展示虚构的业务绑定控件。画笔设置使用原生选择框、滑块和复选框，并提供形态预览；仅在画笔/橡皮模式显示，窄屏换行。画布滚动区可通过键盘聚焦。

要求：空态给出创建入口；区域设置只在选中时出现；锁定背景不可误选；小屏默认收起侧栏且工具栏可换行；状态不能只靠颜色表达；精确创建和层级操作提供原生表单/按钮入口。自由手绘仍需要鼠标、触控或笔输入，不宣称已提供完整的键盘绘画替代方案。
