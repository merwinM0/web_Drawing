# web_Drawing

基于 TypeScript、SVG 和 Bun 的本地绘画应用，包含绘画库首页与工作台。以**框选区域**为编辑单位：先创建一个框，再在框内绘画；多个框可以重叠，并拥有独立笔画、叠放层级和未来的功能绑定。

不再提供“绘制按钮”组件模式，也不能直接在底面背景上绘画。

## 快速开始

需要 Bun 1.3+ 和支持 SVG、Pointer Events 的现代浏览器。

```bash
bun install
bun run dev              # http://localhost:3000
```

指定开发端口：`PORT=3001 bun run dev`。

## 使用流程

1. 首页点击「新建绘画」，输入名称后进入工作台；已有作品可从缩略图列表打开。
2. 使用「框选」在白色画布上拖出矩形，松开后自动切换画笔。
3. 在选中框内起笔，笔刷超出边缘的部分会被裁剪。新建的其他框可以重叠，默认位于最上层。
4. 从左侧列表选择框继续绘画；按 `V` 可选中并拖动框，区域内笔画、橡皮和绑定一起移动。
5. 点击圆形颜色按钮打开自绘色轮：外环选色相，内面板选饱和度/明度，也支持键盘滑块、HEX 和常用色。
6. 在顶部修改作品名称，点击「保存」或按 `Ctrl/Cmd+S`，刷新后仍能从首页继续编辑。
7. 通过顶部「导出」菜单下载网页、SVG 或 JSON。每个框有稳定 ID，后续功能按框绑定，而不是按笔画或层号绑定。

左侧「精确创建区域」支持输入坐标和尺寸，也可通过键盘操作。画布固定为 **1200 × 760**，区域最小 **12 × 12 px**。框线和名称标签仅用于编辑，不会出现在导出图像中。

## 首页与本地保存

- 首页提供新建、作品列表、缩略图、名称搜索、保存时间和删除确认。
- 使用浏览器 **IndexedDB** 保存完整可编辑文档及当前颜色；不会上传到服务器。
- 顶部明确区分保存中、已保存、未保存；离开工作台可选择保存、放弃修改或取消，刷新/关闭也有浏览器离开提醒。
- 保存失败会保留当前编辑内容并提示；多页面编辑存在版本冲突时拒绝覆盖较新内容。
- 这是手动保存，不是自动保存；同一浏览器、同一站点地址下可恢复。清除网站数据、切换端口/域名或无痕窗口结束都可能使作品不可用，请定期导出备份。

参考[绘画库与持久化](docs/DRAWING_LIBRARY.md)。

## 画笔与橡皮

接入 MIT 开源库 [perfect-freehand](https://github.com/steveruizok/perfect-freehand)，提供：

- **四种画笔**：圆头笔、压感墨笔、纹理铅笔、荧光笔。
- **三种橡皮**：硬边圆形、柔边羽化、方形，支持低强度分次擦淡。
- **参数**：大小、透明度/擦除强度、平滑度；每种预设独立记忆页面内设置。
- **压感**：墨笔和铅笔可读取手写笔真实压力；鼠标/触控采用模拟粗细，也可关闭压感。
- **预览**：笔触形态预览与大小光标；所有笔触、纹理和羽化仍受区域裁剪限制。

画笔范围 1–100 px，橡皮范围 1–160 px；橡皮大小直接使用设置值，不再自动乘二。导出 HTML/SVG 不依赖笔刷库或外部纹理。当前实现不等同于专业水彩/油画物理引擎，也不支持外部笔刷包；详见[画笔引擎参考](docs/BRUSH_ENGINE.md)和[第三方许可声明](THIRD_PARTY_NOTICES.md)。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `R` / `V` | 框选新区域 / 选择并拖动区域 |
| 方向键 / `Shift + 方向键` | 选择模式中移动区域 1 / 10 px |
| `Ctrl/Cmd + S` | 保存当前绘画 |
| `P` / `E` | 画笔 / 橡皮 |
| `Esc` | 取消未完成操作，返回画笔；无选中区域时返回框选 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Delete` / `Backspace` | 删除选中区域及其笔画，文本输入时不触发 |

## 导出与部署

- **导出网页**：独立 HTML，内嵌 SVG、样式、区域数据和区域激活事件桥接，可离线打开。当前没有真实业务功能或预设按钮外观。
- **导出 SVG**：包含区域裁剪、透明橡皮和叠放顺序的矢量图。
- **导出 JSON**：下载版本化（当前 `version: 2`，包含笔刷及压力）的区域、笔画和绑定元数据，供后续导入及外部集成使用；当前编辑器尚不支持导入。
- **构建编辑器**：`bun run build` 生成 `dist/`，可部署到任意静态文件服务器，无 Bun 运行时依赖。

> 只有点击保存后，修改才会进入本地绘画库。区域缩放、JSON 文件导入、自动保存、云同步和业务绑定面板尚未实现。

```bash
bun run build

bun run test:e2e
```

浏览器回归覆盖交互、真实像素裁剪/擦除、离线导出事件、四档响应式布局及 axe WCAG 2.1 AA 扫描。详见[开发与测试指南](docs/DEVELOPMENT.md)。

```text
  style.css       工作台样式与响应式布局

  color-wheel.css 色轮与自定义调色控件
```
