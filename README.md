# web_Drawing

基于 TypeScript、SVG 和 Bun 的单页绘画工作台。以**框选区域**为编辑单位：先创建一个框，再在框内绘画；多个框可以重叠，并拥有独立笔画、叠放层级和未来的功能绑定。

不再提供“绘制按钮”组件模式，也不能直接在底面背景上绘画。

## 快速开始

需要 Bun 1.3+ 和支持 SVG、Pointer Events 的现代浏览器。

```bash
bun install
bun run dev              # http://localhost:3000
```

指定开发端口：`PORT=3001 bun run dev`。

## 使用流程

1. 默认使用「框选」工具，在白色画布上拖出矩形；松开后自动切换画笔。
2. 在选中框内起笔。笔刷超出框边缘的部分会被裁剪，不能画到背景或其他框中。
3. 再次选择「框选」可添加新框。新框位于最上层，允许与已有框重叠。
4. 从左侧图层列表选择任意区域继续绘画；或用「选择」工具点击画布，选中命中位置的最上层框。
5. 在区域设置中重命名、上移/下移一层或删除。橡皮只擦除当前框中先前的笔画，擦空处可以透出下层内容。
6. 导出网页、SVG 或 JSON。每个框保留稳定 ID，后续功能按框绑定，而不是按笔画或图层序号绑定。

左侧「精确创建区域」支持输入坐标和尺寸，也可通过键盘操作。画布固定为 **1200 × 760**，区域最小 **12 × 12 px**。框线和名称标签仅用于编辑，不会出现在导出图像中。

| 快捷键 | 操作 |
| --- | --- |
| `R` / `V` | 框选新区域 / 选择已有区域 |
| `P` / `E` | 画笔 / 橡皮 |
| `Esc` | 取消未完成操作，返回画笔；无选中区域时返回框选 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Delete` / `Backspace` | 删除选中区域及其笔画，文本输入时不触发 |

## 导出与部署

- **导出网页**：独立 HTML，内嵌 SVG、样式、区域数据和区域激活事件桥接，可离线打开。当前没有真实业务功能或预设按钮外观。
- **导出 SVG**：包含区域裁剪、透明橡皮和叠放顺序的矢量图。
- **导出 JSON**：下载版本化的区域、笔画和绑定元数据，供后续导入及外部集成使用；当前编辑器尚不支持导入。
- **构建编辑器**：`bun run build` 生成 `dist/`，可部署到任意静态文件服务器，无 Bun 运行时依赖。

> 当前内容仅保存在页面内存中，刷新或关闭会丢失，请及时导出。区域移动/缩放、自动保存和业务绑定面板尚未实现。

## 检查

```bash
bun run typecheck
bun test
bun run build

# 浏览器回归首次运行前安装 Chromium
bunx playwright install chromium
bun run test:e2e
```

浏览器回归覆盖交互、真实像素裁剪/擦除、离线导出事件、四档响应式布局及 axe WCAG 2.1 AA 扫描。详见[开发与测试指南](docs/DEVELOPMENT.md)。

## 源码布局

```text
src/
  app.ts          工具状态与指针交互
  document.ts     区域模型、图层操作与撤销重做
  geometry.ts     框选、命中与局部坐标
  render.ts       SVG 裁剪、橡皮与编辑框线
  export.ts       HTML / SVG / JSON 导出与区域事件桥接
  sidebar.ts      区域列表、属性和精确创建表单
  dom.ts          DOM 查询辅助
  index.html      工作台结构
  style.css       样式与响应式布局
server.ts         Bun 开发入口
tests/            单元测试与浏览器回归
```
